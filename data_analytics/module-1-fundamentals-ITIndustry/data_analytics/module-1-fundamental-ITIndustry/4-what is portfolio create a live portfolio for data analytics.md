# What is a Portfolio?

## Definition


-A portfolio is a curated collection of your actual work — for a data analyst, that means real projects showing the question you asked, the data you used, and what you found. It's proof of skill, not a list of claims. 

-A portfolio can be created as a website, document, or presentation.

-Example: A Data Analyst's portfolio can include their Python, SQL, Excel, Power BI skills, data analysis projects, certificates, and resume.
