# What is a Website?

A **website** is a collection of related web pages and web resources that are hosted on a **web server** and can be accessed through the Internet using a **web browser** such as Google Chrome, Firefox, Safari, or Edge.

A website has a unique **domain name** or web address, such as `example.com`. Websites can contain text, images, videos, forms, animations, and interactive features.

### Examples

* **Google** – Search engine
* **Amazon** – E-commerce website
* **YouTube** – Video-sharing website
* **Wikipedia** – Information/Wiki website
* **LinkedIn** – Social networking website

---

# Basic Components of a Website

A modern website commonly consists of three main parts:

### 1. Frontend

The **frontend** is the part of the website that users see and interact with.

Common technologies:

* **HTML** – Structure of the webpage
* **CSS** – Design and layout
* **JavaScript** – Interaction and functionality

### 2. Backend

The **backend** works behind the scenes. It handles business logic, user authentication, data processing, requests, and communication with the database.

Common backend technologies include:

* Python / Django / Flask
* PHP
* Java
* Node.js

### 3. Database

A database stores and manages website information such as:

* User accounts
* Products
* Orders
* Employee information
* Messages
* Website content

Examples of databases include MySQL, PostgreSQL, MongoDB, and SQLite.

---

# Types of Websites

Websites can be classified according to their **purpose, functionality, and technology**. 

## 1. Static Website

A **static website** contains mostly fixed content. The content changes only when a developer manually modifies the website files.

**Technologies:**
HTML, CSS, JavaScript

**Examples:**

* Portfolio website
* Simple company website
* Landing page
* Brochure website

**Advantages:**

* Easy to develop
* Fast loading
* Simple to host
* Usually inexpensive

---

## 2. Dynamic Website

A **dynamic website** can display different content depending on the user, database, time, or user interaction.

Dynamic websites generally use a **backend and database**.

**Technologies:**
Python/Django, Flask, PHP, Node.js, Java, etc.

**Examples:**

* Social media websites
* News websites
* Online learning platforms
* Banking websites

For example, when a user logs into a website, their name, profile, and other information can be retrieved from a database and displayed dynamically.

---

## 3. E-Commerce Website

An **e-commerce website** allows users to buy and sell products or services online.

**Examples:**

* Amazon
* Flipkart
* Myntra

### Common features:

* Product listing
* Product search
* Search filters
* Shopping cart
* Online payment
* Order management
* Order tracking

---

## 4. Portfolio Website

A **portfolio website** is used to showcase a person's skills, projects, education, achievements, and experience.

It is commonly used by:

* Developers
* Designers
* Photographers
* Freelancers
* Students

For example, a Python developer can use a portfolio website to display their Python and Django projects.

---

## 5. Business/Corporate Website

A **business website** represents a company and provides information about its products, services, and business.

### Common sections:

* Home
* About Us
* Products/Services
* Gallery
* Testimonials
* Contact Us

For example, a manufacturing company can use a business website to display its products, factory information, and contact details.

---

## 6. Blog Website

A **blog website** publishes articles or posts regularly.

### Common topics:

* Technology
* Education
* Travel
* Food
* Finance
* Personal experiences

Blogs can generate income through advertising, sponsorships, affiliate marketing, or subscriptions.

---

## 7. Social Media Website

A **social media website** allows users to create profiles, share content, communicate, and interact with other users.

**Examples:**

* Facebook
* Instagram
* LinkedIn
* X

### Common features:

* User profiles
* Posts
* Comments
* Likes
* Messages
* Followers/Friends

---

## 8. Educational Website

An **educational website** provides learning resources such as courses, tutorials, study materials, quizzes, and examinations.

**Examples:**

* Online course platforms
* School websites
* College websites
* Coding tutorial websites

---

## 9. News Website

A **news website** provides information about current events and publishes news articles.

### Common categories:

* Politics
* Sports
* Business
* Technology
* Entertainment
* World news

---

## 10. Government Website

A **government website** provides official government information and online services to citizens.

### Examples of services:

* Applying for certificates
* Paying taxes
* Checking government schemes
* Downloading forms
* Checking application status
