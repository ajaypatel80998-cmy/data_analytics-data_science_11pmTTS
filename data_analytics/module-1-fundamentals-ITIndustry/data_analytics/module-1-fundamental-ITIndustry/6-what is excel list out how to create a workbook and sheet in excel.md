# What is Excel?

**Microsoft Excel** is a spreadsheet software developed by Microsoft that is used to store, organize, calculate, and analyze data in the form of rows and columns.

Excel is widely used for:

* Data entry and storage
* Calculations using formulas and functions
* Creating charts and graphs
* Data analysis (sorting, filtering, pivot tables)
* Budgeting, accounting, and financial modeling
* Creating reports and dashboards

Excel files are saved with the extension **`.xlsx`** (or `.xls` for older versions).

---

# Basic Structure of Excel

Excel is organized into three main levels:

### 1. Workbook
A **workbook** is the entire Excel file. It can contain one or more sheets.

### 2. Worksheet (Sheet)
A **worksheet**, or **sheet**, is a single page inside a workbook made up of rows and columns.

### 3. Cell
A **cell** is the intersection of a row and a column (e.g., `A1`, `B2`) where you enter data, text, or formulas.

---

# How to Create a Workbook in Excel

### Method 1: From the Start Screen
1. Open **Microsoft Excel**.
2. On the start screen, click **Blank Workbook**.
3. A new workbook opens with one default sheet (usually named `Sheet1`).
4. Press **Ctrl + S** to save it, choose a location, give it a file name, and click **Save**.

### Method 2: From Within Excel
1. Open Excel (any workbook can be open).
2. Click **File** → **New**.
3. Select **Blank Workbook**.
4. A new workbook window opens.

### Method 3: Using Keyboard Shortcut
* Press **Ctrl + N** while Excel is open to instantly create a new blank workbook.

---

# How to Create a Sheet (Worksheet) in Excel

### Method 1: Using the Plus (+) Button
1. Look at the bottom of the Excel window, next to the existing sheet tabs.
2. Click the **`+`** icon.
3. A new sheet is added (e.g., `Sheet2`, `Sheet3`).

### Method 2: Using the Right-Click Menu
1. Right-click on any existing sheet tab at the bottom.
2. Select **Insert** from the menu.
3. Choose **Worksheet** and click **OK**.
4. A new sheet is inserted.
