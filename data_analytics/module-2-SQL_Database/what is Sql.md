
# What Is SQL?

SQL stands for **Structured Query Language**. It is a programming language used to communicate with and manage relational databases.

## What Can SQL Do?

SQL can be used to:

- Create databases and tables
- Insert new data
- Retrieve data
- Update existing data
- Delete data
- Filter, sort, and group data
- Combine data from multiple tables

## Example

```sql
SELECT name, age
FROM students
WHERE age > 18;
```

This query displays the names and ages of students who are older than 18.

## Common SQL Commands

| Command | Purpose |
| --- | --- |
| `SELECT` | Retrieves data |
| `INSERT` | Adds new data |
| `UPDATE` | Modifies existing data |
| `DELETE` | Removes data |
| `CREATE` | Creates database objects |

SQL is commonly used with database systems such as MySQL, PostgreSQL, Oracle Database, Microsoft SQL Server, and SQLite.
